# ron1n.cc

Website for the Ronin GSE tank macros (Retail + WoW: Forever).

- `public/index.html` is the whole site.
- `public/downloads/RoninRetail.zip` and `RoninForever.zip` are the download buttons.
- `wrangler.jsonc` tells Cloudflare to serve `public/` as the Worker named `ron1n`.

Every push to `main` is built and deployed by Cloudflare Workers Builds.

Last release: Ronin Retail V5.0.3, Ronin Forever V1.5.0.
